# 可运行的参考游戏与候选

本目录保存 112 份当前 GameSpec：通用机制参考、Gxx/Hxx 逐款候选，以及作者编写的规则变体。它们由共享 Runtime 执行，CocosAirJS / Three.js 仅负责表现和宿主输入。

“可运行”不代表整款最终通过。基础/变体清单见 `project/game-candidates.json`、`project/rule-variants.json`；完整验收合同见 `project/gameplay-acceptance.json`。作者定义不算独立模型 G3。

历史 `org.a2game.samples.*` 游戏 ID 保持稳定，以保留回放、资源 SHA 和既有证据；命名空间不描述当前项目成熟度。
