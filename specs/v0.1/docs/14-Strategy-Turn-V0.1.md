# Strategy / Economy / Turn Library 0.1.0

本增量提供四个共享行为 Profile：`strategy.economy-loop`、`strategy.path-follow`、`turnbased.turn`、`turnbased.cards`。内部 service Manifest 描述成本、资源、库存、生产、收集、升级、解锁、商店、放置、路径、塔/范围、玩家顺序、合法落子、Deck/Hand 的消费关系；单独声明 service 不代表可以向 JSON 注入任意命令，也不代表完整 G21–G24 游戏通过。

## 经营与共享时间

产品目录定义成本、产量、奖励、成熟 Tick、升级成本和可选解锁条件；Action 映射到有界可信命令。播种先扣成本，收集仅接受成熟且未收集的槽位；收集一次清空槽位并同时增加库存/钱包/分数。重复/提前收集、余额不足、未解锁购买和非法放置均发 invalid 事件，不扣钱、不增加成功次数。升级影响后续收集产量。放置消费库存，网格选择/同值合成事务执行。

生产只使用 Session Tick；暂停、快照和重开沿用核心契约，不读取墙上时间，不实现离线收益。最多 16 个生产槽、256 个经营格、64 个目录/命令；整数余额/库存设上限，超预算不发布部分结果。经营事件可由规则在 T8 映射到其他域状态；下一 Tick 的战斗才消费该升级，不能另起一个生产时钟。

## 路径与回合

`findGridPath` 是有界四邻 BFS，固定左/右/上/下顺序，返回完整格子路径或空。`path-follow` 消费整数 waypoint，每 Tick 使用固定曼哈顿距离预算，按 X 后 Y 移动，可向指定 realtime world 的 Body 提交位置。该行为在 T4，T5 物理边界/碰撞随后结算；路径抵达标记表示路径游标完成，不承诺忽略阻挡后 Body 必然到达。没有完整动态导航网格、避障群体或跨求解器承诺。

`turn` 支持至多 19×19 棋盘、2–4 玩家、可配置连线长度与四个方向判胜。占用格非法输入保留当前玩家及步数；合法输入后按顺序换人，胜利或满盘停止落子。允许多个已接受动作在一个 Tick 按输入顺序消费，不自动按现实时间切换回合。协议未绑定远程玩家身份；联网服务必须另做权限与序列验证。

`cards` 支持有界牌库、手牌、弃牌、抽牌/出牌，以及首次 Tick 使用共享 RNG 的 Fisher–Yates 洗牌；牌总数守恒、满手牌/空牌库不抽牌。最多 128 张牌、32 手牌，Snapshot 精确恢复牌序和 RNG。此 Profile 是本地逻辑合同，浏览器完整状态不构成安全的多人隐藏信息服务。

## 参考与验收

九份参考 JSON：生产收集、升级产量、商店解锁/放置、经营合成、合法落子、Deck/Hand、确定洗牌、路径运动、路径与自动防御组合。数值期望由人工给定；新增三条必要 Node 回归覆盖成本/时间、合法轮换/平局、牌守恒/回放及寻路。`node scripts/mechanism-browser.mjs --suite=strategy` 使用真实 Three.js/CocosAirJS、完整内容准入、相同输入、Node Hash、暂停/重开、截图和资源释放；回执独立存档。Gxx/Hxx、Agent 和真机依旧单独验收。
