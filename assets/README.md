# Reference assets

`checker.png` and `tone.wav` are generated by `scripts/build-reference-assets.mjs` from numerical data in this repository. These two fixtures are dedicated to the public domain under CC0-1.0. They contain no third-party artwork or recordings.

Rebuild with `npm run build` then `node scripts/build-reference-assets.mjs`. Review and commit the resulting bytes together with `project/asset-policy.json`. Uploading a game cannot register resources or change this policy.

`hidden-apple.png` and `hidden-key.png` are repository-authored CC0-1.0 pixel-art objects for H05, generated by `node scripts/build-hidden-assets.mjs`. Their exact PNG bytes, MIME, length and SHA256 are approved in `project/asset-policy.json`; uploaded JSON cannot register additional assets.
