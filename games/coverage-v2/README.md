## 能力复用

- **G90** 用 `a2game.core.state`、`a2game.core.rules`、`a2game.rules.state-set` 与 `a2game.core.flow` 表达分支和结局，选项通过键盘或 Player 按钮提交，文本由 `a2game.visual.scene2d` 投影。首批使用有限分支，台词和转换都写在作品定义中。
- **G58** 继承 G17 Phase 2 revision 5 的持续移动、开火请求与自动瞄准。独立原型聚焦单场 Boss 战。固定发射点的有限波次用 `a2game.realtime.world` 生成标记为 Boss 所有的敌方弹丸，通过共享碰撞扣除护盾。GameSpec 规则根据 Tick 预告并开放反击窗口，核心被击破即结束。两款定义均使用能力版本 `0.1.0`。[G17 基线](../phase2/shooter/README.md)

### 节奏时钟

G161 使用 60 Hz 的唯一 Session Tick。下落位置、按键判定、漏拍和连击读取相同的逻辑时钟。判线时刻预写在谱面，对应的提示音事件在前一 Tick 请求、在判线时刻发布。±3 Tick 是含边界的输入窗口，晚 4 Tick 则记为漏拍。暂停冻结逻辑时钟，音频由现有 Stage 生命周期暂停。输入回放以逻辑 Tick 为准，浏览器音频输出延迟不参与判分。[Stage 音频契约](../../specs/v0.1/docs/11-Visual-Stage-V0.1.md)

Chromium 默认播放器时钟下，Three.js 与 CocosAirJS 各观测到 8 次浏览器原生音频播放调用。两端观测到的调用 Tick 与 8 个音符到达判线的 Tick 逐次相同；测量位于浏览器音频 API 层。[双引擎音画回执](../../reports/coverage-v2-rhythm-clock-1795332090966/summary.json)
